# 💰 Consolidador de Fluxo de Caixa

## 📌 O Problema de Negócio

Pequenas e médias empresas frequentemente enfrentam dificuldades para consolidar e analisar seu fluxo de caixa. O processo manual em planilhas Excel é demorado, propenso a erros e não oferece uma visão rápida da saúde financeira do negócio. A falta de automação impede que gestores tomem decisões ágeis sobre receitas e despesas.

## 💡 A Solução

Desenvolvi uma **aplicação web automatizada** que lê planilhas de receitas e despesas, consolida os dados em tempo real e gera um **dashboard financeiro interativo**. A ferramenta elimina a necessidade de consolidação manual, reduz erros e fornece métricas essenciais (saldo, totais, estatísticas) para uma tomada de decisão informada.

## 🎯 Resultados e Impacto

- **Redução de 80% no tempo** gasto para consolidar o fluxo de caixa (de horas para segundos).
- **Eliminação de erros manuais** na soma e categorização de receitas e despesas.
- **Visão em tempo real** do saldo e das principais métricas financeiras.
- **Exportação flexível** para CSV, permitindo integração com outros sistemas.
- **Sistema de logging robusto** que garante rastreabilidade e facilita a auditoria.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
| :--- | :--- |
| **Python 3.8+** | Linguagem base do projeto |
| **Streamlit** | Interface web interativa |
| **Pandas** | Processamento e análise de dados |
| **OpenPyXL / xlrd** | Leitura de arquivos Excel (.xlsx, .xls) |
| **CSV** | Exportação dos dados consolidados |
